# ZJU Campus Auto Login

浙江大学校园网自动重连小工具，面向 Windows 上长期运行、通过远程桌面访问的实验室电脑。

每小时检查一次校园网认证状态；只有服务器明确返回未认证时才尝试登录。不是“永久在线”或绕过学校会话期限的工具：到期后可能等待接近一小时才恢复，期间远程连接可能中断。

> 非浙江大学或深澜官方产品。仅使用本人获授权的账号，遵守学校网络管理规定。当前适配 `https://net.zju.edu.cn/` 的 SRun 门户，不承诺兼容其他学校或未来门户版本。

## 功能与边界

- 每小时检查，登录 Windows 时额外检查一次。
- 已在线时不读取密码、不重复登录；不发送注销请求。
- 标准库实现 SRun challenge、编码及签名，无第三方 Python 依赖。
- 支持当前校园 DNS 与 Clash/Mihomo TUN 场景；不修改系统代理、DNS、网卡或 Clash 配置。
- 所有认证 HTTPS 请求保留 `net.zju.edu.cn` 主机名和证书校验，不使用跳过 TLS 验证的选项。
- 密码通过 Windows DPAPI 加密，保存在当前用户的本地应用数据目录。
- 遇到验证码、未知认证状态、服务器不可达或登录失败时停止本次操作，不立即反复提交密码。后续计划周期仍会检查。
- **仅在配置它的 Windows 用户已登录时运行。锁屏不影响；注销后不运行，重启后需要先登录该用户。** 电脑睡眠、断电、网线断开时不能保证恢复；不自动唤醒电脑。
- 不负责启动/修复远程控制软件，也不保证远程软件能自行重新连接。

## 环境

- Windows 10/11，Windows PowerShell 5.1、任务计划程序。
- Python **3.10 或更新版本**，包含 `tkinter` 和同目录下的 `pythonw.exe`。推荐使用 [python.org Windows 安装包](https://www.python.org/downloads/windows/)。
- 电脑连接浙江大学校园网，持有有效校园网账号。

Linux/macOS 只用于不依赖 Windows 的协议测试，不支持安装自动登录任务或保存凭据。

## 安装与启用

1. 下载仓库 ZIP 并解压，或克隆仓库。将源码放到当前用户自己的固定目录，**不要放在临时目录或其他用户可修改的共享目录**。
2. 双击 `Setup.cmd`。它依次尝试 `py -3` 和 PATH 中的 `python`，检查版本和 Tk 支持。
   如果使用未加入 PATH 的 Python，可在终端执行：
   ```powershell
   & '你的Python安装目录\python.exe' .\setup_gui.py
   ```
3. 在本机窗口输入账号、密码，阅读校园网登录页面的文明上网承诺后勾选确认。
4. 点击“加密保存并启用每小时任务”。不要把账号密码发送到 GitHub Issue 或聊天窗口。
5. 在任务计划程序中查看 `ZJU-CampusAutoLogin-OpenSource`。首次定时检查约在安装一小时后；之后每小时检查，登录 Windows 时也会检查。

**源码目录和选定的 Python 安装必须保留原位置。** 如果要迁移，先从旧目录移除任务，再从新目录运行设置。安装器拒绝覆盖指向不同目录或不同用户的同名任务。

当前已联网时不会提交密码，因此“设置成功”并不代表密码已验证。不要仅为了测试而远程注销校园网；真实掉线恢复测试建议在有人现场或有备用连接时进行。

## 手动检查与日志

在源码目录打开终端：

```powershell
# 只查询状态，绝不提交登录请求
py -3 .\campus_login.py --check

# 检查状态；仅在确认未认证时使用已保存的凭据登录
py -3 .\campus_login.py
```

退出码：`0` 表示已在线或恢复成功；`--check` 下 `2` 表示明确离线；`1` 表示发生错误或无法安全完成操作。

数据保存在：

```text
%LOCALAPPDATA%\ZjuCampusAutoLogin\
  credentials.dat   DPAPI 加密凭据
  config.json       可选的本机配置覆盖
  campus.log        运行日志（轮转保留）
```

源码目录不保存运行凭据或日志。日志记录在线、恢复和失败原因类别，不记录用户名、密码或完整登录请求。错误日志应先自行检查再公开提交。

## 网络配置与 TUN

默认值位于 `config.example.json`，是开发环境中验证过的校园网络端点，**不是所有校区永久有效的保证**。

本工具先尝试通过本地 SOCKS 服务直连校园 DNS，避开 TUN 的 DNS 接管；本地代理不可用时尝试直接查询校园 DNS。若没有可用的新解析，则尝试示例配置中的引导地址。无论哪条路径，实际认证均验证 `net.zju.edu.cn` 的 HTTPS 证书。本地 SOCKS 请求只用于 DNS；认证请求不显式使用 HTTP/SOCKS 代理，但系统 TUN/VPN 仍可能接管其连接。

校园网络或代理端口不同，可创建 `%LOCALAPPDATA%\ZjuCampusAutoLogin\config.json`，只覆盖需要修改的字段。例如不用 Clash/Mihomo：

```json
{
  "local_socks_port": null
}
```

| 字段 | 含义 |
|---|---|
| `campus_dns` | 校园 DNS 的 IPv4 地址列表 |
| `local_socks_port` | 本机 SOCKS 端口，默认 `7897`；`null` 表示不使用 |
| `bootstrap_ipv4` | 解析不可用时尝试的门户 IPv4 地址列表；学校调整服务器后可能需要更新 |
| `ac_id` | 获取门户页面时使用的初始接入控制器参数；登录使用该页面返回的参数 |

不要盲目关闭 TUN、改默认路由或注销校园网来排查远程主机。若日志提示服务器不可达，应优先核查校园 DNS、代理端口和学校是否更换认证端点。不要通过关闭证书校验“修复”连接问题。

## 停用与卸载

在源码目录执行：

```powershell
# 停用任务，可随时重新启用
Disable-ScheduledTask -TaskName 'ZJU-CampusAutoLogin-OpenSource'

# 移除任务，保留源码和本机数据
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Task.ps1 -Remove
```

需要彻底卸载时，移除任务后再自行删除源码目录和 `%LOCALAPPDATA%\ZjuCampusAutoLogin`。修改校园网密码后重新运行 `Setup.cmd` 更新凭据；连续出现登录拒绝时应先停用任务，确认密码和学校策略。

## 安全与隐私

- DPAPI 保护的是磁盘上的凭据，不是抵御已控制当前 Windows 用户的恶意程序。相同用户下的程序可能解密凭据；管理员也不应视为隔离边界。
- 数据目录设置为当前用户与 SYSTEM 可访问。不要把它放入同步盘、备份分享或公开仓库。
- 密码在认证时必须短暂出现在进程内存中。SRun 使用协议规定的 MD5/SHA-1，不应将其误认为现代密码存储方案；传输安全依赖 HTTPS。
- 按校园协议，登录参数放在 HTTPS GET 查询中。不要开启会记录完整 URL 的调试代理或公开网络抓包；学校服务器也可能记录请求。
- `.gitignore` 排除凭据、日志、本机配置等，但它不能保护此前已经提交到 Git 的秘密。提交前始终检查暂存文件，不要分享整个应用数据目录。
- 无遥测、账号上传或自动更新功能。网络交互限于配置的 DNS、本地 SOCKS 服务和校园认证服务器。

## 开发与验证

```powershell
py -3 -m unittest -v test_campus_login
```

测试使用临时目录，不需要真实账号或校园网络。覆盖官方门户 JavaScript 对照向量、登录签名、未知状态处理、配置边界、数据隔离及 Windows DPAPI（非 Windows 跳过）。

本工具已在 Windows 校园网实测在线查询和计划任务执行；离线认证分支通过模拟流程与协议向量验证。**尚未完成真实断网到重新认证的端到端验证，不应把单元测试通过视为已验证所有账号或校区。**

仓库中的公开测试数据使用示例账号，不包含开发者校园账号或本机凭据。请勿在 CI 中添加校园网密码。
